## PaddleOCR 可选依赖（Linux / Windows 推荐使用）
#
# ⚠️ 注意：
# 1. macOS Apple Silicon (arm64) 对 PaddlePaddle 支持有限，建议直接使用主依赖中的 easyocr

# 3. 启用后在前端「模型配置」 / .env 中将 OCR_PROVIDER 设为 "paddleocr"

#   pip install -r requirements-paddle.txt

#   或 GPU 版（需 CUDA 11.x/12.x）：

#   pip install paddleocr==2.8.1
